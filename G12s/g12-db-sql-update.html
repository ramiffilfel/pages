ما التحديث (التعديل)؟

طالب أعاد امتحاناً فتغيّر معدله، وطالب غيّر رقم هاتفه، والمكتب رفع رواتب المهندسين 10%، والمحل خفّض الأسعار… السجلات موجودة، لكن بعض قيمها تغيّرت.

📌 استعلام التحديث UPDATE
استعلام يُستخدم لتعديل قيم حقول في سجلات موجودة في الجدول، لكل السجلات أو للسجلات التي تحقق شرطاً. لا يضيف سجلات ولا يحذفها، وهو من أوامر DML.
الاستعلامماذا يفعل بالسجلات؟
SELECTيعرضها فقط، ولا يغيّر الجدول.
DELETEيحذف سجلات كاملة.
UPDATEيغيّر قيماً داخل السجلات، ويبقى عدد السجلات كما هو.

UPDATE … SET … WHERE …

UPDATEحدّث tableالجدول SETاجعل field = new_valueالحقل = القيمة الجديدة WHEREبشرط conditionالسجلات المراد تعديلها ;
مثال: عدّل معدل الطالب رقم 2 إلى 50.
👆 اضغط كل جزء من الجملة لتعرف معناه.
⚠️ قواعد مهمة
  • اسم الجدول يأتي بعد UPDATE مباشرة، ولا نكتب FROM ولا INTO.
  • بعد SET: اسم الحقل، ثم =، ثم القيمة الجديدة. ولتعديل أكثر من حقل نفصل بينها بفاصلة: SET st_avg = 50, st_class = "12A"
  • القيمة الجديدة بنفس قواعد الشرط: النص بين " "، والتاريخ بين #، والرقم كما هو.
  • بدون WHERE يُعدَّل الحقل في كل السجلات! ويطلب أكسس تأكيداً، ولا تراجع بعد «نعم».
  • 💡 عاين أولاً بجملة SELECT بالشرط نفسه.
المحطة ٣ · الحالة الأولى: قيمة ثابتة جديدة

SET field = قيمة

نضع قيمة جديدة ثابتة مكان القديمة. بدون شرط تُعدَّل كل السجلات، ومع شرط تُعدَّل السجلات التي تحققه فقط.

المطلوب
المحطة ٤ · الحالة الثانية: إضافة أو طرح قيمة ثابتة

SET salary = salary + 100

القيمة الجديدة تُحسب من القيمة الأصلية: نكتب اسم الحقل نفسه على يمين = ونضيف أو نطرح منه.

SET Salary = Salary + 100
القيمة الجديدة ⟵ القيمة الأصلية + 100:   1500 + 100 = 1600  |  1400 + 100 = 1500
💡 لو كتبنا SET Salary = 100 لصار راتب كل مدير 100! الحقل على يمين = هو الذي يجعل الزيادة على القيمة الأصلية.

× (1 + النسبة)زيادة نسبة

25% ⟵ × 1.25
× (1 − النسبة)خصم نسبة
